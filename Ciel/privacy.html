Privacy Policy

Last Updated: June 12, 2026

This Privacy Policy explains what data the Ciel Discord Bot ("we", "our", "the Bot") collects, how it is used, and how you can manage your data.

1. Data We Collect

To function properly, Ciel collects the following minimum required data:

  • Discord IDs & Profiles: User IDs, Server IDs (Guild IDs), Channel IDs, Display Names, and Avatars (strictly for leaderboard rendering).
  • Server Configurations: Settings specifically configured for your server (e.g., active channels, notification preferences).
  • Server Roles: Role data to verify eligibility for automated prizes and access-gated commands.
  • Parsed Statistics: Card claims, summon counts, and related timer data as outlined in our explicit internal data schema below.
Ciel Bot Internal Data Schema

2. Message Content Intent (Important)

Ciel requires the privileged Message Content Intent to read specific messages—primarily interactions and drop data from the Mazoku bot (Discord ID: 1242388858897956906)—to compile player statistics, track card claims, and provide automated utility. We want to be completely transparent about how message content is handled:

  • Message content (specifically Mazoku bot outputs like card summons) is read in-memory only to parse necessary game data. Ciel does not read, parse, or log normal user messages. Furthermore, Ciel operates exclusively via Slash Commands and utilizes zero legacy prefix commands, guaranteeing that regular user chat is completely ignored.
  • Message content is never stored in any database, logs, or persistent storage.
  • Once a message is processed in-memory, the text content is immediately discarded.

3. Server Members Intent (Important)

Ciel requires the privileged Server Members Intent (GUILD_MEMBERS) to reliably access the full member list of a server. This is necessary for:

  • Role Verification & Prizes: Checking if a winner of a Mazoku drop holds specific roles (e.g., Server Booster, Clan Member) for eligibility. Without this intent, checks for offline/inactive members silently fail.
  • Username Resolution: Allowing players to reference other users by username in commands (e.g., gifting tokens). This requires scanning the full guild member list.
  • Leaderboard Display: Resolving user IDs to display names and avatars for server-wide leaderboards without hitting API rate limits.

Member information is accessed strictly in-memory at the time of each operation and is never persisted, logged, or transmitted to our database.

4. How We Use Your Data

The data we collect is used strictly for the functionality of the Bot. We use this data to:

  • Execute commands requested by users.
  • Maintain server-specific configurations and preferences.
  • Track relevant bot-related statistics as advertised.

5. Data Sharing & Third Parties

We value your privacy. No user data is ever sold, rented, or shared with third parties. All statistics and parsed data are kept entirely within the Ciel Discord Bot ecosystem. We do not use any external analytics services, and no data is exported to third-party dashboards.

6. Data Storage, Retention, and Security

Ciel's core infrastructure is designed with security and privacy in mind:

  • Hosting & Storage: Our database is hosted via MongoDB in Europe (adhering to strict European data protection standards), and the bot is securely hosted on a VPS in Qatar.
  • Logging: We practice strict data minimization. System and error logs are rotated and cleared every 24 hours to ensure no stale data or accidental PII is retained.
  • Retention: Server configuration data is retained as long as the Bot remains in your server. If the Bot is kicked, associated server data may be purged.

7. User Data Deletion

You have the absolute right to request the deletion of any personal data we hold about you. To request data deletion, you must contact us directly via Discord DM or by emailing us using the information below. We will honor all deletion requests promptly.

8. Children's Privacy

In compliance with Discord's Terms of Service and applicable privacy laws (like COPPA/GDPR), Ciel does not knowingly collect or solicit any information from anyone under the age of 13 (or the minimum age of digital consent in your country). If we learn we have collected such information, we will delete it immediately.
